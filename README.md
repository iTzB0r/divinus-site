# Divinus: site institucional

Site da **[Divinus Tecnologia](https://divinustecnologia.com.br)**, empresa de Belém (PA) que faz chatbots com IA, painéis de BI e sites sob medida. Feito em HTML, CSS e JavaScript, com uma função de chat que usa a API da Anthropic.

## Páginas

- `index.html`: página inicial.
- `demo/`: demonstração do chatbot de IA.
- `privacidade/`: política de privacidade.
- `propostas/`: páginas de propostas comerciais.
- `functions/api/chat.js`: função de chat com IA (SDK da Anthropic).

## Como rodar

Abra o `index.html` no navegador. A função de chat precisa da variável de ambiente `ANTHROPIC_API_KEY` no ambiente onde for publicada. Nunca coloque a chave no código.
